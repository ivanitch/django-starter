# Настройка CI/CD (GitHub Actions)

Проект поставляется с готовым пайплайном, который автоматически проверяет код линтерами, прогоняет тесты в реальной базе
PostgreSQL 18 и деплоит изменения на сервер.

Чтобы деплой работал, необходимо предоставить GitHub Actions безопасный доступ к вашему серверу (VPS).

## Шаг 1: Генерация SSH ключа на сервере

Подключитесь к вашему VPS и создайте выделенный SSH-ключ без пароля (`passphrase` должна быть пустой). Этот ключ будет
использоваться только ботом GitHub.

```bash
ssh-keygen -t ed25519 -C "github-actions" -f ~/.ssh/github_actions -N ""
```

## Шаг 2: Добавление ключа в авторизованные

Разрешите вход на сервер по этому ключу:

```shell
cat ~/.ssh/github_actions.pub >> ~/.ssh/authorized_keys
```

## Шаг 3: Копирование приватного ключа

Выведите приватный ключ в консоль и скопируйте его целиком, включая строки `-----BEGIN...` и `-----END...`:

```shell
cat ~/.ssh/github_actions
```

## Шаг 4: Настройка секретов в GitHub

Откройте репозиторий на GitHub и перейдите в `Settings` ➡ `Secrets and variables` ➡ `Actions` ➡ `New repository secret`.
Добавьте переменные:

- `SERVER_HOST` — IP-адрес вашего сервера (например, 63.183.77.237).
- `SERVER_USER` — Имя пользователя сервера (например, root).
- `SERVER_PORT` — Порт соединения (например, 2222).
- `SSH_PRIVATE_KEY` — Скопированный приватный ключ из Шага 3.
