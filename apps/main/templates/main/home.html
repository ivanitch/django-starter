Ultimate Django Starter Kit

Python 3.12+ Django 6.x PostgreSQL Docker TailwindCSS

Why Choose This Starter Kit?

Fail-Fast Security

The production server will refuse to start if the `.env` file is insecurely configured (e.g., missing secret key).

Flawless Docker

No root/user permission conflicts on Linux or Mac. Uses the `uv` package manager for blazing-fast builds.

Tailwind Hot-Reload

Native integration directly inside the local container, without messy local dependencies (no node_modules on the host).

Quick Start

Development should be enjoyable. We use a Makefile to reduce boilerplate and routine tasks. 

git clone https://github.com/ivanitch/django-starter.git
cd django-starter
cp .env.example .env
make up
Building containers... Done!
Starting Django server at http://localhost:8000 🚀
To configure the production environment, check the GitHub documentation.
